K-Shoot Mania v2 の譜面制作支援ツールを開発する

フロントエンドで動作し、1ツールにつき1機能という最小限の規模を維持する。

言語はhtml, css, jsを用いる。将来的にK-Shoot Editorがユーザー定義スクリプトの実行に対応する場合に備え、多言語への翻訳可能性をなるべく維持したわかりやすい設計を行う。（将来的な展望として言及されているにとどまっており、詳細な仕様は非公表である）

toy/kshTools に旧KSM向けのツールがあるが、それの再録は検討していない。
toy/ksonTools で開発を行い、共通する機能は toy/ksonTools/utilities にまとめる。各種ツールは toy/ksonTools/dynamic_effect のようにツールごとのフォルダを持つ。
# ksonTools 開発方針

## ポータルへの掲載

- 各ツールは `ksonTools` 直下に専用フォルダーを作り、入口を `index.html` とする。
- `index.html` の `<head>` に、一覧表示用のタイトルと1行説明を記載する。

```html
<meta name="tool-title" content="ツール名">
<meta name="description" content="ツールの1行説明">
```

- ポータルへ掲載するツールは、`ksonTools.js` の `toolDirectories` にフォルダーを明示的に登録する。
- ツールのページを配置しても `toolDirectories` に登録しなければ一覧には掲載されない。この状態は、URLを知る人だけに試験公開する場合に利用できる。
- ポータルは登録された各 `index.html` から上記2項目を取得する。ディレクトリ一覧による自動検出は行わない。
- `utilities` フォルダーは共通部品用のため、`toolDirectories` に登録しない。
- 各 `index.html` の取得は `file://` では動作しないため、必ずローカルホスト経由で開く。

新しいツールを作成する際は `utilities/template.html` を複製し、タイトル、1行説明、画面内容、読み込むスクリプトを置き換える。
