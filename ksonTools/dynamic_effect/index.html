時間変化エフェクト

Audio effect パラメータ変化の命令列を生成し、時間変化をつくるツール。

使い方
  1. 対象を選択し、エフェクト名を入力します（ユーザー定義エフェクトを推奨）。
  2. 時間変化させるパラメータ名を検索して選択します。
  3. 始点値・終点値・長さ・更新間隔などを設定します。
  4. 「実行」を押し、dynamic_effect.kson をダウンロードします。
  5. K-Shoot Editorでファイルを開き、生成された内容を使用する譜面へコピー＆ペーストします。
注意点

出力位置

2小節目の先頭、すなわち960Yからパラメータ変更命令を作成します。

パラメータ

パラメータ名の候補には、KSONで使用可能なすべてのパラメータを収録しています。ただし、本ツールでは時間変化させることが効果的な一部のパラメータのみ対応しています。対象外のパラメータを選択すると、変化の設定と実行が無効になります。

始点値と終点値

始点値と終点値には、KSONフォーマットで許可される形式のうち、K-Shoot Editorから入力可能な形式を使用できます。パラメータに応じた単位を正しく付けてください。単位がない場合や異なる単位を付けた場合、実行できません。

値が許容範囲を超えている場合も実行できません。入力値の自動補正は行いません。

長さと更新間隔

長さと更新間隔には小数を入力できます。小節、拍、Yのいずれかで入力し、内部ではYに換算して計算します。

Yが整数にならない値も使用できますが、命令を出力する位置は四捨五入して整数Yにします。更新間隔ごとに命令の挿入を試みますが、丸め後のパラメータ値が直前の命令と同じ場合、その命令は削除します。そのため、実際に出力される命令の間隔が設定した更新間隔より広くなることがあります。

「終点に命令を挿入」は、長さが更新間隔の倍数である場合に使用できます。

カーブ

カーブには、直線とべき関数による補間を使用します。いずれも始点を (0, 0)、終点を (1, 1) として計算します。

  • 直線：x
  • ファーストカーブ：√x。開始直後に大きく変化し、その後は緩やかに変化します。
  • スローカーブ：x²。開始時は緩やかで、終点に近づくほど大きく変化します。

精度モード

標準精度では、整数型を整数に四捨五入し、小数型を小数点以下3桁に四捨五入します。

概数では、samples と Hz は1の位を四捨五入して10単位に丸めます。hi_cut_gain、pitch、q、ratio は整数相当の値に丸めます。

標準精度と概数で結果が変わらないパラメータでは、精度モードを選択できません。

Off時の値

mix と ratio では、あらかじめ定義されたOff時の固定値を命令に付加できます。Off値自体を入力したり、時間変化させたりすることはできません。

実行と命令数

入力に問題がなければ、「実行」を押すと dynamic_effect.kson がダウンロードされます。

命令数が多い場合は、ダウンロード前に警告を表示します。警告後も続行できますが、命令数が多い譜面はK-Shoot Editorでの編集や再生処理が重くなる可能性があります。

変化終了後の値

時間変化区間の終了後も、最後に設定したパラメータ値は保持されます。元の値へ戻す命令が必要な場合は、譜面へ別途追加してください。

特に、mix を 0% まで下げた後、同じ名前のエフェクトを再び使用する場合は注意してください。

動作確認環境

本ツールは、K-Shoot MANIA v2.0.1およびK-Shoot Editor v2.1.0を使用して開発・動作確認しています。異なるバージョンでは、エフェクトやパラメータの仕様が異なる可能性があります。
